# Paper

LaTeX source for **Neurons or Subspaces? Calibration-Sensitive Refusal in Open
Instruction Models**, formatted for JMLR with the official `jmlr2e.sty`.

## Author

Varadaraj Acharya — Independent Researcher, Udupi, Karnataka, India —
`varadaraj277@gmail.com`.

## Compile

```bash
./compile.sh
```

or, without a full TeX Live install:

```bash
tectonic -X compile main.tex
```

`jmlr2e.sty` is vendored in this directory. The paper currently uses the
`preprint` option, which removes the JMLR volume/page header. For the final JMLR
submission, remove `[preprint]` and add:

```latex
\jmlrheading{}{2026}{1-\pageref{LastPage}}{}{}{}{Varadaraj Acharya}
```

## Files

```
main.tex            the paper
jmlr2e.sty          official JMLR style
references.bib      bibliography
tables/*.tex        generated by src/make_tables.py
figures/*.pdf       generated by src/make_figures.py
```

To regenerate the tables and figures from the results:

```bash
python src/make_tables.py
python src/make_figures.py
```

## Submission package

`submission/` is ready for the JMLR portal:

```
submission/main.pdf        the 13-page manuscript
submission/source.zip      main.tex, jmlr2e.sty, references.bib, tables/, figures/
submission/cover_letter.txt
submission/metadata.txt    title, author, email, affiliation, keywords, abstract
submission/CHECKLIST.md    the remaining portal steps
```

The header is filled: `Journal of Machine Learning Research (2026) 1-13`,
`Submitted 11/26`. The volume and published fields are blank by design; JMLR fills
them after acceptance. `Editor: Action Editor` is a placeholder for the assigned
action editor.
